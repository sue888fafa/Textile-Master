# 绣线工坊 Godot 版

这是一个独立的 Godot 4.x 原生 2D 版本。打开本目录中的 `project.godot`，运行 `main.tscn` 即可开始游戏。

玩法逻辑位于 `scripts/main.gd`，包括：

- 9:16 竖屏画布与闭环传送带；纺织机不再固定在地图上，而是在合成后从起点进入传送带。
- 五种颜色、双机订单波次、每波 1-5 个单球订单、动态机器数量限制、订单气泡和持续射线绣制。
- 底部四条材料列，每列实际保留 10 枚线团，屏幕显示 3.5 枚；前三个完整可见线团都可以单独取出，最下面半个线团带暗色遮罩且不可取出。
- 每局开场待编制区为空；材料列耗尽后会自动补充 10 枚，优先补当前订单需要的颜色，没有有效需求时改补其他颜色。
- 初始 40 枚材料会整体随机混排到四列中，安全路线校验会验证可通关路线；随机失败时使用打乱过的可解布局兜底。
- 点击材料线团会进入中央五格待编制区；三个同色线团自动合成为一台携带线团的动态纺织机。
- 动态纺织机最多同时运行 5 台，经过对应颜色有效点位最近的传送带位置时进入持续纺织状态。纺织线会从机器当前位置连接到目标方块，并随机器移动改变长度；线头在目标方块内从左到右、从上到下完成 5 条扫描，方块会逐步显示已纺织效果。完成后机器继续运行到终点消失；起点显示运行数量 / 5。
- 订单气泡按单个线团显示，不显示颜色数量；同色需求会占用多个订单气泡位置。三合成功后订单立即显示绿色勾勾并完成，随后气泡移除、后续订单自动向左补位；当前波次全部合成后立即发布下一波，不等待机器纺织完成。
- 待编制区超过 5 枚时失败；没有可用目标的动态机器会把线团返还到待编制区。
- 有效针脚由三合材料生成，低亮度点位为本局装饰点，不计入胜利条件。
- 鼠标、触摸点击和 `R` 键重新开始。

美术替换入口在主场景 Inspector 的 `Art Slots` 分类。可以替换背景、顶部 HUD、订单气泡、棋盘、传送带、五格待编制区、纺织机左/底/右方向资源、5 种毛线球和 5 种已纺织块；没有填入的插槽会继续使用脚本绘制的占位样式。具体顺序见 `assets/README.md`。

布局替换入口在同一个节点 Inspector 的 `Layout - 390x844` 分类。`board_layout_rect` 是绣图区，`belt_panel_rect` 是传送带区域，`recycle_tray_rect` 是中央五格待编制区，4 个 `material_lane_*_rect` 是四条材料列；`belt_path_points` 控制动态纺织机行进轨迹，`dynamic_machine_size` 控制机器大小，`machine_counter_offset` 控制起点计数位置，`machine_counter_size` 控制计数底图尺寸，`order_bubble_offset` 控制整组订单气泡相对传送带起点的位置。顶部 HUD 和底部材料区也可以独立调整。建议保持虚拟画布 390x844 的坐标范围，运行时会自动等比缩放到窗口。

关卡图形编辑入口在 `Main` 节点 Inspector 的 `Level Editing` 分类。`pattern_grid_size.x` 是列数，`pattern_grid_size.y` 是行数；`pattern_layout` 是多行字符网格。使用 `.` 留空，使用 `c/y/g/l`（或 `b`）/`d` 分别放置珊瑚红、向日黄、叶绿色、湖蓝色/深蓝色块。空格也代表留空并保留列位置。行数不足会补空行，超出尺寸会截断，非法字符会按空格处理。

项目还提供了可视化的 `Cross-Stitch Pattern Editor` 插件。打开 `main.tscn` 并在场景树中选中 `Main`，Godot 右侧会显示“编制图案编辑器”面板。设置网格行列数，选择颜色后点击格子即可摆放图案；选择“空白”可以清除格子。点击“应用到 Main”后，再按 `Ctrl+S` 保存场景。插件写入的仍是 `pattern_grid_size` 和 `pattern_layout`，可以继续在 Inspector 中查看或手动微调，应用操作支持 Godot 撤销/重做。

面板顶部的关卡工具可以新增、复制、删除和切换多个关卡。首次点击“+”时，会把 Main 当前的单关兼容配置复制成第 01 关；之后每个关卡独立保存名称、网格尺寸和图案。完成当前关卡后，运行时会自动进入下一关；`Main` 的 `start_level_index` 可以设置开局关卡序号（从 0 开始）。如果 `level_configs` 为空，游戏继续使用旧的单关配置。

例如把 `pattern_grid_size` 设置为 `Vector2i(9, 9)`，并在 `pattern_layout` 输入以下 9 行内容：

```text
..cc.....
.cggc....
cggggc...
.cggc....
..cc.....
.........
.........
.........
.........
```

保存场景后，运行时会使用同一份配置。脚本使用 `@tool`，因此修改尺寸或布局文本后，Godot 编辑器画布会自动刷新编制区域预览；编辑器中只显示预览，不会推进传送带或纺织动画。空图案也是合法配置，运行时会安全显示为完成状态。

顶部右侧不再显示待编制区数量；中央五格区域上方仍保留 `X / 5` 容量提示。材料初始顺序会整体随机化，并通过安全路线检测保证仍存在可通关顺序。
